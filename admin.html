Operations

This page shows how the machine is running. It cannot show who anybody looked up. There is no column in the operations schema for the identifier a user searched, the party a check was about, or the result it returned, and there will not be one. A table holding that would rebuild the person-level file the product was rebuilt to refuse. What it costs is a search-history screen. What it buys is that there is nothing here to disclose on an access request and nothing to breach.
Metrics per OPS-001 s.51. Evidence pack per s.52. Served by /api/admin-metrics, which is disabled outright when ADMIN_TOKEN is unset rather than left open.
